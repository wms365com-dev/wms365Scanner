WMS365 Partner API v1

Customer-scoped access to inventory, orders, shipments, and import jobs.

Authentication

Exchange approved client credentials at POST /api/v1/oauth/token. Access tokens expire after one hour. Refresh tokens rotate when used.

Safety Rules

Every token is limited to one customer company and explicit scopes. Send Idempotency-Key on every write. Page sizes are limited to 200 records.

Endpoints

POST/api/v1/oauth/token
GET/api/v1/inventory
GET/api/v1/orders
GET/api/v1/shipments
GET/api/v1/jobs
POST/api/v1/jobs
GET/api/v1/jobs/{id}/errors.csv
