WMS365 Customer Guide

Connect Shopify to WMS365

Use this guide when your warehouse needs to pull Shopify orders, sync inventory, and send shipment confirmations from WMS365.

WMS365 app URL:
https://app.wms365.co

WMS365 will send you a separate secure one-time link for the Shopify Admin API access token. Do not email the token in a normal message.

What WMS365 Needs

InformationWhat to Provide
Shopify store domainYour .myshopify.com domain, for example your-store.myshopify.com.
Admin API access tokenThe token from a Shopify Custom App. It usually starts with shpat_.
Shopify locationThe Shopify location that should receive WMS365 inventory updates, if inventory sync is enabled.
Important: Do not send your Shopify password, owner login, recovery codes, or billing access. WMS365 only needs the scoped Admin API token.

Step 1: Open Shopify Custom Apps

  1. Log in to your Shopify Admin as a store owner or administrator.
  2. Open Settings.
  3. Open Apps and sales channels.
  4. Open Develop apps. If Shopify asks you to allow custom app development, approve it only if your company policy allows it.
  5. Create a new custom app named WMS365, or open your existing WMS365 app if one was already created.

Step 2: Configure Admin API Scopes

Select only the scopes needed for your WMS365 workflow.

ScopeWhy WMS365 Uses It
read_ordersPull released Shopify orders into WMS365.
read_productsRead product and variant details for SKU matching.
read_inventoryRead Shopify inventory item/location data.
write_inventoryPush WMS365 available inventory back to Shopify, if enabled.
read_locationsFind the correct Shopify location for inventory sync.
read_fulfillmentsCheck fulfillment status before sending shipment confirmation.
write_fulfillmentsSend carrier/tracking confirmation after WMS365 ships the order.

Step 3: Install the Custom App

  1. After selecting the scopes, click Save.
  2. Click Install app.
  3. Shopify will show the Admin API access token one time. Copy it carefully.
  4. Keep the Shopify page open until the token has been submitted successfully to WMS365.

Step 4: Submit the Token Securely

  1. Open the secure WMS365 credential link provided by your warehouse or WMS365 support team.
  2. Paste the Shopify Admin API access token into the secure page.
  3. Submit the form. The link can only be used once and expires automatically.
  4. Notify your warehouse contact that the token has been submitted. They will test the connection from WMS365.

What Happens Next

  • WMS365 stores the token encrypted under your company only.
  • WMS365 can pull Shopify orders into the warehouse system.
  • When orders ship, WMS365 can send shipment confirmations and tracking back to Shopify.
  • If inventory sync is enabled, WMS365 can push available stock to the selected Shopify location.
Support: If you are unsure which scopes to select, contact support@wms365.co before installing the Shopify Custom App.
